# Drop screenshots here

Anything from Instagram — profile grids, single posts, reels. Filenames do not
matter.

**Most useful, in order:**

1. **Profile grids** of the eight competitors. One screenshot shows a whole
   creator's recent range, and reel tiles carry view counts — which the API
   cannot give us for other accounts.
2. **Their best posts**, opened, so likes and comments are visible.
3. **Their worst posts.** Genuinely important. A file of only winners cannot
   show what separates them.
4. **Anything outside real estate that made you stop scrolling** — format ideas
   travel between niches better than topics do.
